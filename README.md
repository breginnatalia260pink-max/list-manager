# List Manager

Консольний застосунок на Python для роботи зі списком елементів. Навчальний проєкт для вивчення Git, GitHub та Python.

## Опис

Цей проєкт є простим менеджером списку з текстовим інтерфейсом, який дозволяє додавати, переглядати, видаляти, підраховувати та очищати елементи списку під час роботи програми.

## Функціональність

- Додавання елементів до списку
- Перегляд поточного списку
- Видалення елементів зі списку
- Підрахунок кількості елементів
- Очищення всього списку

## Додаткові модулі

> Програма працює зі списком у пам'яті та може бути розширена окремими модулями.

| Модуль | Формат | Призначення |
| :--- | :---: | :--- |
| `validator.py` | `.py` | Перевіряє введений текст перед додаванням |
| `templates.json` | `.json` | Зберігає готові початкові списки |
| `history_log.txt` | `.txt` | Фіксує виконані дії та події |

### Логіка роботи з файлами

1. Завантажити початковий шаблон із `templates.json`
2. Перевірити новий елемент у `validator.py`
3. Зафіксувати дію в `history_log.txt`
